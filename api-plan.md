# План разработки REST API

## Цель

Создать простой API для управления пользователями.

## Маршруты API

- GET /users - получить всех пользователей
- GET /users/:id - получить одного пользователя
- POST /users - добавить пользователя
- PUT /users/:id - изменить пользователя
- DELETE /users/:id - удалить пользователя

## Технологии

- Node.js
- Express
- PostgreSQL
